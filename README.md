## calendar-with 장점

1. **업무와 개인 일정 통합 관리** : 여러 개의 구글 계정을 연결해 하나의 캘린더에서 모든 일정을 관리

2. **비밀 일정 공유** : 일정 세부 사항을 숨긴 채로도 일정 공유 가능

3. **다양한 기기에서 사용 가능** : Windows, Mac, Android, iOS, watch 에서 모두 사용 가능

4. **알림 기능** : 평일 오전에 오늘 일정, 월요일엔 주간 개인 일정을 리포트

5. **캘린더 초대 및 편집 권한** : 가족, 동료 등과 일정 초대를 공유하고 함께 일정 편집 가능

6. **캘린더 화면 다운로드** : 특정 달의 캘린더 화면을 다운로드, 일정 항목 블러 처리 또는 일정 가능한 날만 표시 가능

<br/>

## 페이지 설명

메인 페이지

- 통합된 캘린더 뷰 (일간, 주간, 월간 보기 옵션)
- 여러 계정의 일정을 색상별로 구분하여 표시
- 빠른 일정 추가 버튼

일정 관리 페이지

- 새 일정 추가 및 기존 일정 편집 폼
- 비밀 일정 설정 옵션
- 반복 일정 설정

알림 설정

- 계정 연결 페이지
- 구글 계정 연결 및 관리 인터페이스
- 연결된 계정별 일정 표시 설정

공유 설정 페이지

- 일정 공유 대상 관리
- 공유 권한 설정 (보기 전용, 편집 가능 등)
- 초대장 발송 인터페이스

알림 설정 페이지

- 일간, 주간 알림 설정
- 알림 시간 및 빈도 조정
- 알림 수신 방법 선택 (이메일, 푸시 알림 등)

캘린더 다운로드 페이지

- 월별 캘린더 선택 인터페이스
- 다운로드 옵션 설정 (일정 블러 처리, 가능한 날만 표시 등)
- 다운로드 형식 선택 (이미지, PDF 등)

설정 페이지

- 앱 테마 및 언어 설정 (추후 나중 나중에)
- 기본 캘린더 뷰 설정
